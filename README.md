# Simulating a Wonik Allegro robotic hand grasping objects of varying stiffness in MuJoCo
Robotic hands need to adapt their grip to an object's stiffness, but conventional fixed-gain control, which implies having a fixed behavioural sequence tailored to a specific set of physical properties, cannot distinguish between a “weak” grip and a “strong” grip and when each is needed. We investigate this problem in a MuJoCo simulation of a Wonik Allegro hand grasping objects of equal size and shape but varying stiffness (rigid, medium, soft). First, we run an identical, non-adaptive grasp sequence across all three objects and show that stiffness alone produces systematically different outcomes in fingertip force, palm force, and object drift. This is concrete evidence that a fixed controller fails in structurally different ways at each end of the stiffness range. We then build and calibrate a single-joint Extended State Observer (ESO) to test whether this missing stiffness information can be estimated from the joint state alone, without a force sensor. The observer reliably separates soft from not-soft contact and preserves the correct stiffness ordering at steady state but does not cleanly resolve rigid from medium at peak contact, and closing the control loop around its estimate (active ADRC compensation) worsens tracking rather than improving it. We report this as a partial, informative result: joint-state-only sensing can support a coarse stiffness distinction, but not yet a fully adaptive controller.

Environment: Python + MuJoCo (with mujoco_menagerie/wonik_allegro on the path), NumPy, Matplotlib, Jupyter. No GPU or external dataset required; all figures/tables are regenerated from scratch on each run.
Clone mujoco_menagerie (https://github.com/google-deepmind/mujoco_menagerie) and ensure mujoco_menagerie/wonik_allegro/ is accessible from the notebook's working directory!
